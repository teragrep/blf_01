= BLF_01: Tokenizer Library for Java

BLF_01 is a high-performance Java library designed to split extremely large inputs into hierarchical lexical tokens (major and minor) using configurable delimiters.
By generating nested minor tokens for each major token, BLF_01 enables highly accurate pattern matching and deep analysis of unstructured data.

== Example of Tokenization

For input `[20/Feb/2022:03.456]`

- Generated major tokens: `[`, `20/Feb/2022:03.456`, `]`
- Generated minor tokens for the major token `20/Feb/2022:03.456`: `20`, `Feb`, `2022`, `03`, `456`, `/`, `:`, `.`, and all possible permutations, such as `20/Feb`, `20/Feb/2022`.

Note: You can see the major and minor token splitters in `MajorDelimiters` and `MinorDelimiter` classes.

== Limitations

- Compiles to Java 8 bytecode; Java 8 is the minimum required runtime version.
- Verified to build and run with JDK 11 and JDK 17. Compatibility with other Java versions has not been verified.

== How to Use in Code

1. First, add the BLF_01 dependency to your project's Maven POM or Gradle build file.
2. Pass an `InputStream` to the tokenizer to retrieve a list of all major and minor tokens:
+
[source]
----
import com.teragrep.blf_01.Tokenizer;
import com.teragrep.blf_01.Token;

Tokenizer tokenizer = new Tokenizer();
List<Token> tokens = tokenizer.tokenize(inputStream);
----
+
To prevent performance bottlenecks on massive inputs, you can cap the number of generated minor tokens per major token:
+
[source]
----
Tokenizer tokenizer = new Tokenizer(10L);
----
+
If you only need the major tokens, you can disable minor token generation entirely:
+
[source]
----
Tokenizer tokenizer = new Tokenizer(0L);
----
